GenGrowth 是运行在 gengrowth.ai 与 app.gengrowth.ai 上的 SEO / GEO 诊断工作台。
本政策说明我们收集什么、为什么收集、保存多久，以及你可以要求我们做什么。

本文是对照软件的实际行为写的。凡是提到具体 cookie、数据表或授权范围的地方，
写的都是真实的那一个。

## 我们是谁

GenGrowth（下称"我们"）运营本站及相关产品。任何隐私相关问题，包括下文"你的权利"
中的各项请求，请通过文末"联系方式"与我们联系。

## 我们收集什么

### 1. 运行 SEO Agent 时

SEO Agent 需要已验证的 GenGrowth 账号。使用 Google 登录会以第 3 节
所述身份信息创建该账号，但不会授予我们 Gmail 邮箱、Search Console 或站点所有权
访问权限。不运行网站抓取的部分计算器仍可在没有账号的情况下使用。

- **你提交的网址。** 我们会抓取该网址下同源的公开静态 HTML 并分析响应内容。
- **你的 IP 地址。** 它被用作限流计数器的键，以防单个访客耗尽共享的抓取预算。
  该计数器存储在我们的数据库中，**键中包含 IP 地址**。
- **抓取结果的短期副本**，以目标主机名为键，使一小时内的重复请求不必再次抓取
  他人站点。该缓存 **1 小时**后失效。

Agent 运行之前已存在已验证账号；本次营销站运行不会创建已保存的 App 项目或持久化报告。

### 2. 连接 Google Search Console 时

两个工具（流量下滑诊断、快速见效项）会读取你的 Search Console 数据。连接时我们
向 Google 申请的权限**只有一个**：

`https://www.googleapis.com/auth/webmasters.readonly`

该权限是**只读**的。我们无法提交站点地图、无法请求收录、无法更改设置，也无法向
你的资源写入任何内容。我们不申请任何其他敏感权限。

由此获得的访问令牌，以及用于续期的刷新令牌，都以加密的 HTTP-only cookie 形式
保存在**你自己的浏览器**中，仅在需要它的 API 请求上回传给我们。保留刷新令牌是
为了让你再次访问时不必重新经过同意屏幕；它在该 cookie 中保存 30 天，每次使用后
顺延，自授权当日起最长 90 天。我们的服务器不留存副本。这两个工具不会把你的
Search Console 数据写入我们的数据库；分析在请求内完成，结果直接返回浏览器。

### 3. 登录时

使用 Google 登录会向我们提供你的**姓名和邮箱地址**，仅此而已。我们用它们标识你的
账号，并就服务相关事项与你联系。

### 4. 加入等候名单或订阅时

我们存储你提交的**邮箱地址**，以及提交来源页面、界面语言和来源渠道。若你后续
填写了可选的补充信息，我们还会存储你填写的**姓名、公司和职位**。

### 5. 分析统计

我们使用 Google Analytics 4（衡量 ID `G-71TET2Y97Q`）了解哪些页面被阅读、哪些
工具被使用。它会设置 `_ga` 和 `_ga_71TET2Y97Q` 两个 cookie。Google 依据其自身
条款作为独立控制者处理这部分数据。

## 我们不做什么

- 不出售个人数据。
- 不使用你的数据、你的 Search Console 数据或你审计的站点来训练机器学习模型。
- 不申请任何 Google 产品的写入权限。
- 不投放广告，不使用跨站追踪像素。

## 保存多久

| 数据 | 保留期 |
| --- | --- |
| Agent 抓取缓存 | 1 小时 |
| 限流计数器（含 IP） | 直至计数窗口结束 |
| Search Console 访问令牌与刷新令牌 | 仅存于你浏览器的 cookie 中；30 天，每次使用后顺延，自授权起最长 90 天 |
| 账号姓名与邮箱 | 直至你删除账号 |
| 等候名单邮箱与补充信息 | 直至你要求移除 |
| 分析统计 | 按 Google Analytics 4 默认设置 |

## 在哪里处理

我们的数据库与文件存储运行在 Supabase 的美国区域（`us-west-2`）。应用托管在
Vercel，后台任务运行在 Railway。若你位于欧洲经济区或英国，这意味着你的数据会被
传输至美国。

## 你的权利

依据你所在地的法律，你可能享有访问、更正、删除、导出个人数据，反对或限制处理，
以及撤回同意的权利。你可以随时在任一已连接的工具页点击**断开**，它会在同一步里
清除该 cookie 并向 Google 撤销我们的读取权限；退出登录同样如此。你也可以在
[Google 账号权限页](https://myaccount.google.com/permissions)断开 Search Console
授权，我们的读取权限会立即失效。

如需提出请求，请通过文末方式联系我们。我们会在适用法律要求的期限内答复。

## 未成年人

本服务不面向儿童，我们不会在知情的情况下收集 16 岁以下人士的数据。

## 变更

本政策变更时，我们会更新页首的版本号与生效日期。重大变更会在生效前另行告知。
