本条款适用于你对 gengrowth.ai、app.gengrowth.ai 及其上发布的免费工具（下称
"本服务"）的使用。使用本服务即表示你接受本条款。

## 1. 本服务是什么

GenGrowth 是面向搜索与生成式引擎可见性的诊断工作台。它读取公开页面，并在你授权
的情况下读取你自己的 Google Search Console 数据，据此给出发现与建议动作。

它是一个**分析工具**。它不会向你的网站、CMS 或 Search Console 资源发布、修改或
写入任何内容。

## 2. 账号

你可以通过 Google 登录创建账号。你有责任保管好该 Google 账号。若你认为账号被
未经授权使用，请及时告知我们。

SEO Agent 与 Tech Agent 会在接受网站 URL 进行审计前验证账号。该账号门槛不会授予
我们 Gmail 邮箱、Search Console 或站点所有权访问权限。

对违反本条款的账号，我们可以暂停或关闭。

## 3. 免费工具与合理使用

SEO Agent 与 Tech Agent 免费运行，但需要已验证账号；不运行网站抓取的计算器仍可在
没有账号的情况下使用。网站 Agent 只读取公开静态 HTML，不要求 Search Console 授权
或站点所有权验证。它们运行在共享的抓取预算之上，因此按访客和按目标站点分别限流，
且每次运行在页面数量和耗时上都有上限。本次营销站 Agent 运行不会保存到 App 项目。

你同意不：

- 规避或试图规避限流；
- 提交你既不拥有、也无正当理由审计的网址，若这样做会给目标站点造成负担；
- 利用工具攻击、压垮任何站点，或探测其安全面；
- 转售、再分发工具输出，或将其作为独立审计产品对外呈现。

我们可以随时撤下、变更或限制任何免费工具。

## 4. 你的数据与授权

你的内容与 Search Console 数据的所有权归你。你仅授予我们完成你所请求的分析所需
的权限 —— 一个 **只读** 的 Search Console 权限，且你可以随时撤销。

个人数据的处理方式见[隐私政策](/zh/privacy)。

## 5. 准确性，以及"发现"不是什么

本服务基于公开响应和第三方提供商数据给出观察与推断。搜索引擎和生成式引擎不公开
其排序逻辑，第三方指标本身是估算值。

因此：

- 一条"发现"是供你决策的证据，不是排名结果的保证；
- 我们不保证依据某条发现采取行动就会提升流量、排名或可见度；
- 在把任何建议变更应用到线上站点之前，复核的责任在你。
