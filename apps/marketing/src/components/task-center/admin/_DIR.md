# apps/marketing/src/components/task-center/admin

Client controls for `/admin/tasks`. Chinese only, like the admin pages. Every request goes through `admin-fetch.ts` to the same-origin admin API, which answers 404 to anyone not on `TASK_ADMIN_EMAILS`.

- `admin-fetch.ts` — JSON fetch to the admin API and the Chinese message for each error code and each field problem a form can cause.
- `drama-quick-create.tsx` — 查剧 on `/admin/tasks`: title, platform and an optional language; one exact match from 选剧台 is imported straight away (for ReelShort, StardustTV, MoboReels, NetShort and YourChannel, with the details from the theater's own site) and opens its page with a note on where the details came from, several (or only near ones) are listed to pick from with 「都不是，手填」, and none, 其他平台 or an unconfigured lookup opens `DramaForm` with what was typed. Also the tag chips the admin drama page reuses.
- `drama-form.tsx` — the manual create and the edit of a drama's details (中文名 optional, tags comma separated, 频道 and 题材 for the clip grid's filters; 题材 suggests common genres and refuses 男频/女频 words) and promo target; a new drama opens its own edit page. `PromoLinkForm` saves just the promo target and sub-channel parameter, the part 查剧 cannot fill.
- `drama-admin-controls.tsx` — publish, take down (archived: off the list, existing promo links still redirect), back to draft, cover and clip upload straight from the browser to R2 with progress (one button opens the file picker, or files are dropped on the box, and picking starts the upload; one file at a time, the button locked from the first click so a double click cannot upload twice, then the server verifies size and type; a cover is only checked for type, a non-zero size and the 20 MB cap), a clip type picked before upload, a still cut from the clip's first second in the browser and uploaded beside it (a failure only means no still), the 改标题 rename and retag select on each clip, and asset delete.
- `account-review-buttons.tsx` — 通过 / 拒绝 for one account on `/admin/tasks/accounts`, then a refresh; either can be pressed later to change the answer.
- `settlement-import-form.tsx` — pick a CSV and a currency, import it, and list each problem line or unclaimed code when the file is refused.
