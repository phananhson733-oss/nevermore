# apps/marketing/src/components/task-center/admin

Client controls for `/admin/tasks`. Chinese only, like the admin pages. Every request goes through `admin-fetch.ts` to the same-origin admin API, which answers 404 to anyone not on `TASK_ADMIN_EMAILS`.

- `admin-fetch.ts` — JSON fetch to the admin API and the Chinese message for each error code and each field problem a form can cause.
- `drama-quick-create.tsx` — 查剧 on `/admin/tasks`: title, platform and an optional language; one exact match from 选剧台 is imported straight away (for ReelShort, StardustTV, MoboReels, NetShort and YourChannel, with the details from the theater's own site) and opens its page, several (or only near ones) are listed to pick from with 「都不是，手填」, and none, 其他平台 or an unconfigured lookup opens `DramaForm` with what was typed; on a miss 选剧台's 剧库 rows of that title (`inCatalog`) either fill the form (the 剧库 has it on this platform but 北斗 has nothing, as for every FlickReels drama) or offer 「换成 X 查」 for the platforms where it has it. While it waits it says 剧库 (ReelShort, StardustTV, MoboReels, NetShort, first 3 s) or 北斗. Also the tag chips the admin drama page reuses.
- `drama-form.tsx` — the manual create and the edit of a drama's details (中文名 optional, tags comma separated, 频道 and 题材 for the clip grid's filters; 题材 suggests common genres and refuses 男频/女频 words) and its platform link (optional, https only: where the drama page's 去看全集 goes; promo links open our own page either way); a new drama opens its own edit page. `PromoLinkForm` saves just the platform link and the sub-channel parameter, the part 查剧 cannot fill.
- `drama-admin-controls.tsx` — publish (a large brand-gradient 上架 button, placed under the clips, on the right, on the drama page), take down (archived: off the list, existing promo links still open the drama's page), back to draft, 从官网补全资料 (re-runs 查剧 for the drama and writes what it finds over its details; says whether the theater's page or only 选剧台 answered and how the cover went, or why nothing changed: no match, several dramas of that title, or another listing of the same drama, with a link to it), cover and clip upload straight from the browser to R2 with progress (one button opens the file picker, 选择文件夹上传 picks a whole folder, or files and folders are dropped on the box, and picking starts the upload; a batch is sorted by file name with numbers read as numbers (第2集 before 第10集), since upload order is the 1, 2, 3 that 系列资源 shows, and files of another type or over the cap are skipped and named while the rest go up; a typed title is numbered across a batch; one file at a time with the batch position in the progress line, the button locked from the first click so a double click cannot upload twice, then the server verifies size and type; a cover is only checked for type, a non-zero size and the 20 MB cap), a clip type picked before upload (高光 unless changed), a still cut from the clip's first second in the browser and uploaded beside it (a failure only means no still), the 改标题 rename and retag select on each clip, and asset delete.
- `account-review-buttons.tsx` — 通过 / 拒绝 for one account on `/admin/tasks/accounts`, then a refresh; either can be pressed later to change the answer.
- `settlement-import-form.tsx` — pick a CSV and a currency, import it, and list each problem line or unclaimed code when the file is refused.
- `drama-quick-create.test.tsx` — jsdom tests with `adminFetch` faked: a miss offers the platform the 剧库 has the drama on (once per platform and language) or fills the form from the 剧库 on this platform, never from another language than asked; the waiting note says 剧库 or 北斗; switching ReelShort → FlickReels end to end.
