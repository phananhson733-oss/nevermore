## 0. 先定下来的事

- **剪辑好的素材：Cloudflare R2，不经过我们的服务器和隧道。** 2026-11-05 用户定的：运营上传现成剪辑好的资源，直接传到 R2。Cloudflare 自助套餐的条款（CDN 一节，2026-09-28 版）要求用付费服务（Developer Platform、Stream 这类）才能经它发视频，经隧道转发不行，R2 属于 Developer Platform。做法：服务端发一个有时效的上传地址，浏览器直接 PUT 到 R2；推广者预览、下载也走有时效的地址，直接从 R2 取。R2 单次上传上限约 5 GB，一个剪辑几十 MB，不需要分片，也碰不到隧道单请求 100 MB 的限制。桶私有，只给一个限定在这个桶上的 R2 API 令牌；桶上要配 CORS，允许 gengrowth.ai 发 PUT。
- **登录：沿用现在的 Google 登录。** 只是这几块数据不放 Supabase。用户在新库里用登录态里的用户 ID 认，不另建账号体系。
- **管理员：邮箱白名单。** `TASK_ADMIN_EMAILS` 里列的邮箱登录后能进后台，别的人进不去，接口返回 404。
- **只跑一个实例**，和营销站现在一样。

## 1. 范围

做：

- 顶部导航加「任务中心」`/tasks` 和「我的收益」`/earnings`。
- 任务列表：按平台、语言筛选，按剧名搜索，排序有最新上架、推广人数，分页。
- 任务详情：剧集信息、简介、目录（按集数和收费起始集显示，后面的带锁）、运营上传的剪辑素材，可以预览、下载。
- 四个推广按钮（TikTok、Facebook、Instagram、YouTube）：没登录先弹 Google 登录；登录后领取，生成这个人、这部剧、这个渠道专属的推广链接和口令码，可以复制，同时记进「我的任务」。
- 我的收益：要登录，不让搜索引擎收录。汇总卡片和按平台的收益表，数字来自管理员导入的结算数据，没有导入时显示「—」，不显示 0。
- 管理员后台 `/admin/tasks`：新建、编辑、上下架短剧；上传封面和剪辑好的素材；导入结算数据。后台只有中文。

做的时候另外定的：

- 任务列表、详情、我的收益、后台都不让搜索引擎收录（`noindex`），也不进 sitemap。
- 素材只给登录的人看、下载；封面谁都能看。视频单个不超过 4 GB，图片不超过 20 MB，类型限 MP4、MOV、WebM 和 JPG、PNG、WebP。浏览器传完以后服务端去 R2 核对大小和类型，对上了才对推广者显示。
- 下架的剧从列表里消失，已经发出去的推广链接照常跳转，不让推广者的链接突然失效。
- 结算导入是整份文件全过才算：有一行格式不对，或者有一个推广码不是我们发的，整份不导，把问题行和推广码列出来。同一个推广码同一天再导会覆盖上一次。

不做：邀好友横幅、小说库、提现、收款账户、个税、数据导出。涉及资金的都不做。

## 2. 表（`gengrowth_tasks` 库）

迁移放在 `apps/marketing/db/tasks/`，编号顺序执行，和 `supabase/migrations/` 分开。不进 `packages/db`，那是 `apps/web` 的合同。只用普通 PostgreSQL，属主不是超级用户也能建。

| 表 | 存什么 |
|---|---|
| `dramas` | 一部剧一行：剧名、中文名、平台、语言、集数、收费起始集、简介、封面的 R2 键、上架时间、状态（草稿、上架、下架）、推广目标地址 |
| `drama_assets` | 运营上传的素材一个一行：视频或图片、标题、R2 键、大小、类型、上传状态、排序 |
| `task_claims` | 领取记录：用户 ID、剧、渠道、推广码、领取时间。同一个人、同一部剧、同一个渠道只有一条 |
| `promo_clicks` | 推广链接被点的记录：哪条领取记录、时间。不存访客 IP |
| `earning_imports` | 管理员每次导入一行：谁导的、什么时候、文件名、币种、条数 |
| `earnings` | 导入的明细：日期、哪条领取记录、订单数、广告金额、收益（金额存成这个币种最小单位的整数，美元是分，日元就是元；币种单列）。平台从领取记录对应的剧来。导入里没有的就是没有，存 null，不补 0 |

推广人数从 `task_claims` 数，不是我们编的数字。

## 3. 推广链接

推广链接是 `https://gengrowth.ai/t/<推广码>`：记一次点击，再 302 到这部剧的推广目标地址。目标地址由管理员在后台填，一般是平台给我们分销账号的那条链接；平台支持子渠道参数的话，把推广码带过去，结算时就能按推广码对回到人。短链 `/go/<code>` 在 Supabase 里，这里不复用，任务中心只用自己的库。

## 7. 结算文件

CSV，UTF-8（带不带 BOM 都行），第一行表头，之后每个推广码每天一行：

```csv
date,code,orders,ad_amount,income
2026-11-04,k7m2xq9p,12,30.50,8.25
```

表头也可以写中文：日期、推广码、订单数、广告金额、收益。日期和推广码必填，后三列至少填一列；空着的格子按「平台没给」处理，前台显示「—」。金额按导入时选的币种的常规小数位写。一份最多 20000 行、2 MB。真实的平台结算文件拿到以后再对一次列名，对不上就在导入前转一下，或者在 `settlement-csv.ts` 里加别名。

## 8. 第二期：照 RS Boost 补齐推广者这边（2026-11-06）

用户定的方向：运营只上传自己剪好的素材，这个站是给推广者拿去发 TikTok、Facebook 的，不做从 ReelShort 抓数据自动填。前台照 RS Boost 补四块：

- **一键拿链接。** 详情页不再分四个渠道，只有一个「一键获取推广链接」按钮，点了给这个人、这部剧一条链接和口令码，各平台都用这一条。新领的记成渠道 `all`（迁移 `0002`，只放宽约束，旧镜像照常跑）；以前按渠道领的码继续跳转，在「我的推广」里照样列出来。领取仍然是一次 POST，不是打开页面就生成，免得预取页面就发出码。
- **「我的推广」`/promotions`。** 每条链接：剧名、渠道（新的写「通用」）、点击数、领取时间，链接和口令码都能复制。原来在「我的收益」底下的链接表挪到这里，收益页只放结算数字。三页顶上有同一排标签：任务中心 / 我的推广 / 我的收益。网站顶部导航不加第三个，1280 宽下七个已经刚好放满（第 0 节和 header 注释里量过）。
- **素材下载和使用说明。** 素材按 1、2、3… 编号成按钮，点了直接下载；预览收进「预览素材」折叠里。下面一块「使用说明」四步：下载素材、复制链接、发 TikTok/Facebook 并先报白账号、结算后在「我的收益」看。文案不写分成比例或金额，我们手上没有这个数。
- **账号报白。** 推广者在「我的推广」里提交 TikTok 或 Facebook 账号（@用户名或主页链接），看到「待报白 / 已报白 / 未通过」。一个人最多 20 个；同一个账号再交一次返回原来那条，不会把已经审过的打回待审；还在待报白的可以撤回；运营处理过（通过或拒绝）的不能撤回，否则删掉被拒的再交一次就把拒绝洗掉了。同一个人同时提交几个也不会超过 20 个（按用户加锁）。提交时把登录邮箱一起存下来，运营才知道是谁。后台 `/admin/tasks/accounts` 列出全部，待报白的排前面，点「通过」或「拒绝」，记下是哪个管理员、什么时候点的；点错了可以再点另一个。报白本身要运营自己去平台上做，我们这里只记结果。

## 9. 第三期：素材广场（2026-11-06）

用户看了 MoboBoost 的「素材广场」，要任务中心首页换成一格一格的素材，而不是一部一部的剧。剧的详情页 `/tasks/<id>` 留着。

- **首页 `/tasks` 是素材格子。** 每格一条已上架剧的可用素材，竖版 9:16，左上角是类型（解说、混剪、高光、预告、整集，没标就不显示），中间播放键，下面是剧封面小图、剧名、素材名，再一行「女频 · Romance · 英语」。按最新上架或推广人数排。能按名字搜（剧名、中文名、素材名，`%` 和 `_` 按字面算），按语言、频道（女频/男频）、题材、类型、平台筛。点一格弹窗：登录了就直接播、下载、拿推广链接；没登录给登录入口。草稿和已下架的剧、没传完的素材都不出现。
- **本周爆款。** 最近 7 天领链接的不同人数最多的前 3 部已上架的剧，至少有 1 个人领过；它们的每条素材都挂「本周爆款」。人数一样时最近有人领的排前，再按 id。每次读页面现算，不存表。没人领就一个都不挂，不拿编辑推荐冒充。
- **新字段（迁移 `0003`，只加可空列）。** 剧加「频道」`audience`（female/male）和「题材」`genre`（小写英文 slug，如 romance、werewolf），素材加类型 `clip_type` 和截图 `poster_key`。后台编辑页能填，素材列表每条都能改类型，旧素材补标签不用重传。中文名本来就是可选的，标签上写明了。
- **截图。** 上传视频时浏览器从本地文件里截第 1 秒左右的一帧（最高 960 像素的 JPEG），和视频一起直传 R2 的 `dramas/<id>/posters/<素材id>.jpg`。完成时服务端只认那个固定的 key，HEAD 核对是 JPEG、大小不超过 20 MB 才记上，库里的约束也只允许这条路径，删素材时就不可能删到别的文件；截不出来或传失败只记日志，不影响视频本身可用，格子里就用剧封面（后台页面只在截图真的传上去以后才带 `posterKey`，所以格式不对的 `posterKey` 被 400 拒掉只可能来自手写请求，不会卡住正常上传）。地址里的剧 id 先转小写再拼 key，手敲大写 id 也不会撞上库里的约束。重试完成时不会把已有的截图清掉。删素材连截图一起删。这之前传的素材没有截图，显示剧封面。
- **后台「预览」打不开的修复。** 原来链接是渲染页面时签的，15 分钟就过期，页面开久了点「预览」R2 就报 ExpiredRequest。现在「预览」指向 `/api/admin/tasks/assets/<id>`，点的时候才签一个新的 15 分钟链接再 302 过去，只给管理员、只对已传完的素材。
- **为什么上传了推广者看不到。** 草稿或已下架的剧推广者完全看不到，素材也下不了。后台编辑页现在会写明这一点，没填推广目标地址的还会提示先填再上架。
