# SEO Agent 剩余验收修复与上线

用户已批准：完成上轮剩余修复、提交并上线。范围包含上轮未提交的 UI/复制修复。

## 设计与边界

- 6.1 新增真实逐页入链计数，从本次抓取的独立其他来源页面计算，排除自链接。完整抓取可以判断零；抓取不完整仅判断实际存在的正值，未知不是零。原 sitemap-only C1 不变。
- 新增中立记录要求共享抓取 schema 升为 v19；v18 缓存当 miss，保留旧客户端缺省 key-pages 的请求兼容，不修改积分。
- noindex 保留观测；仅与已采集 sitemap 的收录声明冲突才为阻断。其他 noindex 放入“仅观测”，显示 URL 与核对意图说明，不自动删除指令、不按路径白名单。
- 图片、真实用户性能、实验室页面体积的失败原因隔离；主动超时单独表述。不得用实验室值冒充真实用户数据。
- 生产性能密钥为 Sensitive，不可导出。运行时可用性在发布后的真实调用验收，不把变量存在或本地缺少值当作生产测量结果。
- 仅 GitHub 当前仓库与 Marketing 发布目标在范围内；不做数据库迁移、密钥轮换或付费来源扩展。没有向外部 ChatGPT Pro 上传源码；原生只读子代理辅助审查，主代理最终验收。

## 验收清单

1. 入链：根页、非 sitemap 页、正值、零、自链接、重复来源、抓取缺口、key-pages 档位、旧缓存 miss。
2. noindex：收录声明冲突为 blocker，未知意图不扣分、不伪装 pass，混合页面仍展示所有限制。
3. 性能：图片异常不污染 field 原因；lab 缺失不归因 field；timeout 与其他失败分开；真实生产调用必须记录真实状态。
4. UI/复制：保留上轮逐页绑定、12px、无供应商用户提示、分级颜色与中英文响应式测试。
5. 发布：当前基线合并、相关/全量门禁、独立 review、精确提交/PR、生产 READY/SHA/alias、生产域名 canary。
